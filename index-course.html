LESSON 01

What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of a webpage.

What can HTML do?

HTML can create headings, paragraphs, images, links, lists, tables, forms and many other elements of a website.

💡 HTML creates the structure of a website. CSS makes it beautiful and JavaScript makes it interactive.

Your First HTML Code 

<h1>Hello World!</h1>

This code creates a large heading containing "Hello World!".
